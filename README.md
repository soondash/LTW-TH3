## Hướng dẫn cài đặt và khởi chạy

Yêu cầu môi trường: Đã cài đặt **Node.js** 

### Phần A: Class Component (`part-a-class`)
Mở cửa sổ dòng lệnh (Terminal / Command Prompt) tại thư mục gốc của dự án và chạy:
```bash
cd part-a-class
npm install
npm start
```
Ứng dụng sẽ tự động mở trên trình duyệt tại: `http://localhost:3000`

### Phần B: Function Component + Hooks (`part-b-hooks`)
Mở một cửa sổ Terminal mới (hoặc tab mới) và chạy:
```bash
cd part-b-hooks
npm install
npm start
```
Ứng dụng sẽ tự động mở trên trình duyệt tại: `http://localhost:3001`
